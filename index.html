01 — Visión General

¿Qué es Flyvest?

Una plataforma SaaS de nueva generación que supera tecnológicamente a soluciones legacy como Inveragil, solucionando problemas de caídas, fragmentación, interfaces obsoletas y pérdida de datos.

📱

Mobile-First Real

89.8% de interacciones desde móvil. Diseño ergonómico para trabajo en campo con una sola mano. Operación completa en 2-3 toques.

📡

Local-First & Offline

El dispositivo es la fuente de verdad. SQLite/Isar local con sincronización CRDT hacia Supabase cuando hay conexión. Cero pérdida de datos.

🖨️

Impresión Térmica Universal

Motor ESC/POS para Bluetooth Classic, BLE, USB OTG y TCP/IP. Comprobantes de 58mm y 80mm con QR, sin depender de internet.

🤖

IA Integrada (Gemini API)

Chat de asistencia inteligente con Google AI Studio / Gemini API vía Supabase Edge Functions. Contexto autorizado del negocio.

🔒

Continuar con Google (OAuth)

Autenticación universal en 1 toque en móvil y web con Google OAuth. Multi-tenant con PostgreSQL Row Level Security (RLS).

💰

$0 Costo de Entrada

Cero costos de instalación para el cliente. Ventaja competitiva directa contra los $200-$500 de setup de la competencia.

03 — Features del Producto

8 Features, 1 Plataforma

Cada feature tiene su especificación completa con criterios de aceptación, plan de implementación y checklist de tareas.

001

Auth & Multi-Tenant Isolation

Google OAuth ("Continuar con Google"), Row Level Security (RLS) por tenant, RBAC con 4 roles, sesiones offline en Flutter.

002

Local-First Engine & CRDT Sync

Operación 100% offline, UUIDs locales con Vector Clock, sincronización idempotente, log de eventos inmutable.

003

Core de Ventas, Préstamos y Cartera

Créditos (interés fijo/francés), cobro rápido en 2 toques con feedback háptico, caja y arqueo diario.

004

Motor de Impresión Térmica ESC/POS

Multi-protocolo (BT Classic, BLE, USB OTG, TCP/IP), formatos 58mm/80mm, QR dinámico, resiliencia de conexión.

005

Rutas de Cobro y Geolocalización

Ordenamiento inteligente por GPS (TSP 2-Opt), geocercas de validación, navegación a Google Maps/Waze, monitoreo en vivo.

006

Panel Web de Administración

Métricas en tiempo real, administración de cartera, exportación multi-formato (Excel, PDF, JSON), API REST documentada.

007

Super-Admin de Amplify

Gestión interna de tenants, control de facturación Lemon Squeezy, Kill Switches, métricas globales de operación.

008

Monetización con Lemon Squeezy

Planes escalonados (Starter/Pro/Enterprise), checkout embebido, webhooks → Supabase, feature gating por plan.
